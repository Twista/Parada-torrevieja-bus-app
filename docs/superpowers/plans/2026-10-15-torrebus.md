# Torrebus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mobilní PWA pro autobusy v Torrevieji (Avanza), která funguje přes mobilní data, ukazuje odjezdy, mapu trasy a v režimu „Jedu“ hlídá, kde vystoupit.

**Architecture:** Statický frontend (Vite + Preact) na Cloudflare Pages. Jediná Pages Function `/api/*` volá avanzagrupo JSON API, normalizuje data a cachuje je v edge cache (Cache API). Telefon mluví jen s naší doménou; service worker drží data offline.

**Tech Stack:** TypeScript, Vite, Preact, preact-iso, MapLibre GL + OpenFreeMap, vite-plugin-pwa (Workbox), Vitest, Wrangler (Cloudflare Pages + Functions).

**Spec:** `docs/superpowers/specs/2026-10-15-torrebus-design.md`

## Global Constraints

- UI texty česky. Názvy zastávek španělsky (z API, bez přípony ` _TRV`).
- Časová zóna pro „dnes“ a „teď“ je vždy `Europe/Madrid`, nikdy zóna telefonu.
- Žádné API klíče. Podkladová mapa: `https://tiles.openfreemap.org/styles/liberty`.
- Upstream: `https://torrevieja.avanzagrupo.com`, JSON přes `index.php?option=com_avanzainfo&task=...`, hlavička `Accept: application/json`.
- Naše API: `GET /api/lines`, `GET /api/lines/:id/:dir`, `GET /api/lines/:id/:dir/schedule?date=YYYYMMDD`, `GET /api/stops`; `:dir` ∈ `I`, `V`; edge cache 24 h; hlavičky `x-stale` (`0`/`1`) a `x-fetched-at` (ms epoch).
- Mimo trasu = dál než 300 m od úseku mezi zastávkami.
- Odhad příjezdu na konečnou: 15 km/h vzdušnou čarou, minimálně 1 min.
- Kód bez komentářů. Commit messages bez Co-Authored-By / AI atribuce.
- Package manager: npm. Cloudflare Pages projekt: `torrebus`.

## Review Focus

1. **Okružní linka (071 „C“)**: směr `V` má prázdné `variants` → žádná záložka „Zpět“, nic nepadá; v režimu „Jedu“ se poloha u společné výchozí/konečné zastávky nesmí skokem vrátit na začátek. Testy: Task 3 (prázdný `V`), Task 6 (`minSegment`).
2. **Den bez provozu / minulý den**: upstream vrací `{"cabecera":[],"paradas":[]}` → prázdný rozpis, UI „Tento den linka nejezdí“ s hledáním dalšího dne. Test: Task 3.
3. **Upstream vrátí captcha HTML nebo `{"error":"Error de conexión con el API"}`**: nesmí se uložit do cache jako platná data; vrátí se starší cache s `x-stale: 1`, jinak 502. Testy: Task 3, Task 4.
4. **Konečná zastávka varianty**: čas z API je nesmyslný (čas odjezdu z výchozí) → pro konečnou se čas odhaduje, na konečné se neukazují „odjezdy“. Testy: Task 5, Task 10.
5. **Telefon v jiné časové zóně (Česko) a půlnoc / změna času**: „dnes“ a „teď“ podle Madridu, časy `24:xx` nepadají. Testy: Task 2.

`src/lib/time.ts`:
```ts
const TZ = 'Europe/Madrid'

const formatter = new Intl.DateTimeFormat('en-GB', {
  timeZone: TZ,
  year: 'numeric',
  month: '2-digit',
  day: '2-digit',
  hour: '2-digit',
  minute: '2-digit',
  hourCycle: 'h23',
})

export function madridNow(date = new Date()): { date: string; minutes: number } {
  const parts = Object.fromEntries(formatter.formatToParts(date).map((p) => [p.type, p.value]))
  return { date: `${parts.year}${parts.month}${parts.day}`, minutes: Number(parts.hour) * 60 + Number(parts.minute) }
}

export function toMinutes(hhmm: string): number {
  const [h, m] = hhmm.split(':').map(Number)
  return h * 60 + m
}

export function formatMinutes(total: number): string {
  const m = ((total % 1440) + 1440) % 1440
  return `${String(Math.floor(m / 60)).padStart(2, '0')}:${String(m % 60).padStart(2, '0')}`
}

export function addDays(yyyymmdd: string, days: number): string {
  const d = new Date(Date.UTC(+yyyymmdd.slice(0, 4), +yyyymmdd.slice(4, 6) - 1, +yyyymmdd.slice(6, 8) + days))
  return d.toISOString().slice(0, 10).replaceAll('-', '')
}

export function formatDate(yyyymmdd: string): string {
  return `${+yyyymmdd.slice(6, 8)}. ${+yyyymmdd.slice(4, 6)}.`
}

export function toIsoDate(yyyymmdd: string): string {
  return `${yyyymmdd.slice(0, 4)}-${yyyymmdd.slice(4, 6)}-${yyyymmdd.slice(6, 8)}`
}

export function fromIsoDate(iso: string): string {
  return iso.replaceAll('-', '')
}
```

export interface RawLineDetail {
  geojson?: { features?: { geometry?: { type: string; coordinates: unknown } }[] }
}

export interface RawSchedules {
  paradas?: Record<string, { hora: string; hasta: string }[]>
  error?: unknown
}

export function cleanStopName(name: string): string {
  return name.replace(/\s*_[A-Z]+$/, '').trim()
}

function match(text: string, re: RegExp): string {
  return text.match(re)?.[1] ?? ''
}

export function parseLines(html: string): Line[] {
  return html
    .split('class="avanzainfo-line-item"')
    .slice(1)
    .map((block) => ({
      id: match(block, /data-line-id="([^"]+)"/),
      label: match(block, /avanzainfo-line-badge[^>]*>\s*([^<]*?)\s*</),
      name: match(block, /avanzainfo-line-name">([^<]*)</).replace(/\s+/g, ' ').trim(),
      color: match(block, /data-line-color="([^"]+)"/),
    }))
}

export function parseLineDirection(lineId: string, dir: Dir, trayectos: RawTrayectos, detail: RawLineDetail): LineDirection {
  const variants = (trayectos.trayectos ?? []).map((t) => ({
    id: t.codtray,
    name: t.nomtray,
    stops: t.paradas.map((p) => ({
      id: p.codigo,
      name: cleanStopName(p.nombre),
      lat: Number(p.coordinates[1]),
      lng: Number(p.coordinates[0]),
    })),
  }))
  const shape = (detail.geojson?.features ?? []).flatMap((f) =>
    f.geometry?.type === 'MultiLineString' ? (f.geometry.coordinates as [number, number][][]).filter((s) => s.length > 1) : [],
  )
  return { lineId, dir, variants, shape }
}

export function parseSchedule(lineId: string, dir: Dir, date: string, raw: RawSchedules): Schedule {
  if (typeof raw.error === 'string') throw new Error(raw.error)
  const stops: Record<string, StopTime[]> = {}
  for (const [key, times] of Object.entries(raw.paradas ?? {})) {
    stops[key.replace(/^P_/, '')] = times.map((t) => ({ time: t.hora, to: t.hasta }))
  }
  return { lineId, dir, date, stops }
}

export function buildStopIndex(directions: LineDirection[]): StopIndexEntry[] {
  const index = new Map<string, StopIndexEntry>()
  for (const d of directions) {
    for (const v of d.variants) {
      for (const s of v.stops) {
        const entry = index.get(s.id) ?? { ...s, serves: [] }
        if (!entry.serves.some((x) => x.lineId === d.lineId && x.dir === d.dir)) entry.serves.push({ lineId: d.lineId, dir: d.dir })
        index.set(s.id, entry)
      }
    }
  }
  return [...index.values()]
}

export interface CacheLike {
  match(req: Request): Promise<Response | undefined>
  put(req: Request, res: Response): Promise<void>
}

const KEEP_SECONDS = 14 * 86400

function respond(res: Response, stale: boolean): Response {
  const out = new Response(res.body, res)
  out.headers.set('x-stale', stale ? '1' : '0')
  out.headers.set('cache-control', 'no-cache')
  return out
}

export async function cachedJson(
  cache: CacheLike,
  key: string,
  ttlSeconds: number,
  produce: () => Promise<unknown>,
  now = Date.now(),
): Promise<Response> {
  const req = new Request(key)
  const hit = await cache.match(req)
  const fetchedAt = Number(hit?.headers.get('x-fetched-at') ?? 0)
  if (hit && now - fetchedAt < ttlSeconds * 1000) return respond(hit, false)
  try {
    const res = new Response(JSON.stringify(await produce()), {
      headers: {
        'content-type': 'application/json; charset=utf-8',
        'cache-control': `public, max-age=${KEEP_SECONDS}`,
        'x-fetched-at': String(now),
      },
    })
    await cache.put(req, res.clone())
    return respond(res, false)
  } catch (err) {
    if (hit) return respond(hit, true)
    return Response.json({ error: String(err) }, { status: 502 })
  }
}

export interface LatLng {
  lat: number
  lng: number
}

const EARTH_M = 6371000
const SPEED_KMH = 15

function rad(deg: number): number {
  return (deg * Math.PI) / 180
}

export function distanceM(a: LatLng, b: LatLng): number {
  const dLat = rad(b.lat - a.lat)
  const dLng = rad(b.lng - a.lng)
  const h = Math.sin(dLat / 2) ** 2 + Math.cos(rad(a.lat)) * Math.cos(rad(b.lat)) * Math.sin(dLng / 2) ** 2
  return 2 * EARTH_M * Math.asin(Math.sqrt(h))
}

export function travelMinutes(a: LatLng, b: LatLng): number {
  return Math.max(1, Math.round((distanceM(a, b) / 1000 / SPEED_KMH) * 60))
}

import type { Schedule, Variant } from '../../shared/types'
import { travelMinutes } from './geo'
import { toMinutes } from './time'

export function stopTimes(schedule: Schedule, variant: Variant, index: number): number[] {
  const last = variant.stops.length - 1
  if (index === last && index > 0) return []
  const terminal = variant.stops[last]?.id
  const times = (schedule.stops[variant.stops[index].id] ?? []).filter((t) => t.to === terminal).map((t) => toMinutes(t.time))
  return [...new Set(times)].sort((a, b) => a - b)
}

export function upcoming(times: number[], now: number, count: number): number[] {
  return times.filter((t) => t >= now).slice(0, count)
}

export function currentTripAnchor(schedule: Schedule, variant: Variant, index: number, now: number): number | null {
  const times = stopTimes(schedule, variant, index)
  const due = times.filter((t) => t <= now + 2)
  return due.length ? due[due.length - 1] : (times[0] ?? null)
}

export function tripFrom(schedule: Schedule, variant: Variant, anchorIndex: number, anchorTime: number): (number | null)[] {
  const trip: (number | null)[] = variant.stops.map(() => null)
  const last = variant.stops.length - 1
  trip[anchorIndex] = anchorTime
  let prev = anchorTime
  for (let i = anchorIndex + 1; i <= last; i++) {
    const next = i === last ? prev + travelMinutes(variant.stops[i - 1], variant.stops[i]) : stopTimes(schedule, variant, i).find((t) => t >= prev)
    if (next === undefined) break
    trip[i] = next
    prev = next
  }
  return trip
}

export interface RoutePosition {
  segment: number
  fraction: number
  distance: number
}

function projectOnSegment(p: LatLng, a: LatLng, b: LatLng): { t: number; distance: number } {
  const k = Math.cos(rad(a.lat))
  const ax = a.lng * k
  const bx = b.lng * k
  const px = p.lng * k
  const dx = bx - ax
  const dy = b.lat - a.lat
  const len2 = dx * dx + dy * dy
  const t = len2 === 0 ? 0 : Math.min(1, Math.max(0, ((px - ax) * dx + (p.lat - a.lat) * dy) / len2))
  return { t, distance: distanceM(p, { lat: a.lat + t * dy, lng: (ax + t * dx) / k }) }
}

export function locateOnStops(stops: LatLng[], p: LatLng, minSegment = 0): RoutePosition | null {
  let best: RoutePosition | null = null
  for (let i = Math.max(0, minSegment); i < stops.length - 1; i++) {
    const { t, distance } = projectOnSegment(p, stops[i], stops[i + 1])
    if (!best || distance < best.distance) best = { segment: i, fraction: t, distance }
  }
  return best
}

export function nearest<T extends LatLng>(items: T[], p: LatLng, count: number): (T & { distance: number })[] {
  return items
    .map((item) => ({ ...item, distance: distanceM(p, item) }))
    .sort((a, b) => a.distance - b.distance)
    .slice(0, count)
}

import type { Dir, Line, LineDirection, Schedule, StopIndexEntry } from '../shared/types'
import { addDays } from './lib/time'

export interface Loaded<T> {
  data: T
  stale: boolean
  fetchedAt: number
}

async function get<T>(path: string): Promise<Loaded<T>> {
  const res = await fetch(path)
  if (!res.ok) throw new Error(`HTTP ${res.status}`)
  return {
    data: (await res.json()) as T,
    stale: res.headers.get('x-stale') === '1',
    fetchedAt: Number(res.headers.get('x-fetched-at') ?? 0),
  }
}

export const api = {
  lines: () => get<Line[]>('/api/lines'),
  direction: (lineId: string, dir: Dir) => get<LineDirection>(`/api/lines/${lineId}/${dir}`),
  schedule: (lineId: string, dir: Dir, date: string) => get<Schedule>(`/api/lines/${lineId}/${dir}/schedule?date=${date}`),
  stops: () => get<StopIndexEntry[]>('/api/stops'),
}

export async function findNextServiceDate(lineId: string, dir: Dir, from: string, days = 7): Promise<string | null> {
  for (let i = 0; i < days; i++) {
    const date = addDays(from, i)
    const { data } = await api.schedule(lineId, dir, date)
    if (Object.keys(data.stops).length > 0) return date
  }
  return null
}

import { useEffect, useState } from 'preact/hooks'

export interface AsyncState<T> {
  data?: T
  error?: unknown
  loading: boolean
}

export function useAsync<T>(fn: () => Promise<T>, deps: unknown[]): AsyncState<T> {
  const [state, setState] = useState<AsyncState<T>>({ loading: true })
  useEffect(() => {
    let alive = true
    setState((s) => ({ data: s.data, loading: true }))
    fn().then(
      (data) => alive && setState({ data, loading: false }),
      (error) => alive && setState({ error, loading: false }),
    )
    return () => {
      alive = false
    }
  }, deps)
  return state
}

    type: 'FeatureCollection',

  }
}

  if (!stops.length) return
  const bounds = new maplibregl.LngLatBounds()
  stops.forEach((s) => bounds.extend([s.lng, s.lat]))
  map.fitBounds(bounds, { padding: 40, duration: 0, maxZoom: 16 })

import { useEffect, useState } from 'preact/hooks'
import type { LatLng } from './geo'

export function useGeolocation(enabled: boolean): { position: LatLng | null; error: string | null } {
  const [position, setPosition] = useState<LatLng | null>(null)
  const [error, setError] = useState<string | null>(null)
  useEffect(() => {
    if (!enabled) return
    if (!('geolocation' in navigator)) {
      setError('unsupported')
      return
    }
    const id = navigator.geolocation.watchPosition(
      (p) => {
        setPosition({ lat: p.coords.latitude, lng: p.coords.longitude })
        setError(null)
      },
      (e) => setError(e.message || 'error'),
      { enableHighAccuracy: true, maximumAge: 5000, timeout: 20000 },
    )
    return () => navigator.geolocation.clearWatch(id)
  }, [enabled])
  return { position, error }
}

import { useEffect } from 'preact/hooks'

export function useWakeLock() {
  useEffect(() => {
    let lock: WakeLockSentinel | null = null
    const request = () => {
      navigator.wakeLock
        ?.request('screen')
        .then((l) => {
          lock = l
        })
        .catch(() => {})
    }
    const onVisible = () => {
      if (document.visibilityState === 'visible') request()
    }
    request()
    document.addEventListener('visibilitychange', onVisible)
    return () => {
      document.removeEventListener('visibilitychange', onVisible)
      lock?.release()
    }
  }, [])
}

import type { LineDirection, Schedule, StopIndexEntry } from '../../shared/types'
import { api } from '../api'
import { stopTimes } from './schedule'

export interface Departure {
  lineId: string
  to: string
  time: number
}

export function departuresFromSchedule(schedule: Schedule, direction: LineDirection, stopId: string, now: number): Departure[] {
  const seen = new Set<string>()
  const result: Departure[] = []
  for (const variant of direction.variants) {
    const to = variant.stops[variant.stops.length - 1]?.name ?? ''
    variant.stops.forEach((s, i) => {
      if (s.id !== stopId) return
      for (const time of stopTimes(schedule, variant, i)) {
        const key = `${to}|${time}`
        if (time < now || seen.has(key)) continue
        seen.add(key)
        result.push({ lineId: direction.lineId, to, time })
      }
    })
  }
  return result.sort((a, b) => a.time - b.time)
}

export async function departuresAt(stop: StopIndexEntry, date: string, now: number): Promise<Departure[]> {
  const lists = await Promise.all(
    stop.serves.map(async ({ lineId, dir }) => {
      const [schedule, direction] = await Promise.all([api.schedule(lineId, dir, date), api.direction(lineId, dir)])
      return departuresFromSchedule(schedule.data, direction.data, stop.id, now)
    }),
  )
  return lists.flat().sort((a, b) => a.time - b.time)
}
